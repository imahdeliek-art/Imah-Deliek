Cara Pasang Aplikasi di HP

📱 Di Android (Google Chrome):
1. Buka tautan web aplikasi ini di Chrome.
2. Ketuk ikon titik tiga (⋮) di pojok kanan atas.
3. Pilih "Instal aplikasi" atau "Tambahkan ke Layar Utama".

🍏 Di iPhone (Safari):
1. Buka tautan web aplikasi ini di Safari.
2. Ketuk tombol Bagikan (ikon kotak dengan panah atas di bawah layar).
3. Gulir ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).

⚡ Pasang Pintasan / Widget Cepat di Layar HP

🤖 Di HP Android (Pintasan 1-Ketuk):
1. Di Layar Utama HP, tekan dan tahan lama ikon aplikasi Kas Keluarga.
2. Menu pintasan cepat akan muncul: "Catat Pengeluaran", "Catat Pemasukan", "Catat Tabungan".
3. Tahan dan seret menu tersebut ke layar utama. Ikon tersebut kini menjadi tombol widget 1-ketuk langsung ke form pencatatan!

🍏 Di iPhone (Widget via Aplikasi 'Pintasan' / Shortcuts):
1. Buka aplikasi bawaan Pintasan (Shortcuts) di iPhone.
2. Buat Pintasan Baru (+) > Tambah Tindakan > Cari "Buka URL".
3. Masukkan link web aplikasi Anda ditambah ?action=catat (contoh: https://kas-keluarga-kami.netlify.app?action=catat).
4. Simpan, lalu pasang sebagai Widget di Layar Utama iPhone. Cukup 1 ketukan langsung terbuka ke form catat!
